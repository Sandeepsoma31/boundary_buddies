Go live for the whole group

This file is a functional prototype. To make it a real shared portal, publish the front end and use a central database with server-enforced admin permissions.

  1. Create a Firebase project at console.firebase.google.com.
  2. Enable Firebase Authentication. Give the admin a sign-in; friends can view the order without edit rights.
  3. Create a Cloud Firestore database. Store each match by date with selected player IDs, current order, version, and order history.
  4. Deploy this site using Firebase Hosting. Configure Firestore Security Rules so only the authenticated admin can create/replace an order; viewers can read it.
  5. Share the resulting Hosting URL in your group chat.
Important: local browser storage cannot synchronize phones or guarantee persistence if browser data is cleared. The live deployment needs the database and security rules above before using it for a real match.
